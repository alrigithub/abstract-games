YINSH AND TZAAR — STONE PIECES

Ten separate GLB 2.0 assets using the same generated black and ivory stone source textures as the Tak pieces.

YINSH: ring-black, ring-white, marker-black, marker-white.
The ring opening clears the marker. Markers are separate color-state meshes, not a single reversible two-color mesh.
TZAAR: tzaar-black/white (double concentric raised bands), tzarra-black/white (single ring), tott-black/white (solid recessed center).
The three TZAAR types use the same outer diameter and nominal thickness for stacking.

Each GLB contains one mesh, standard PBR stone material, embedded 1024px color texture and tangent-space normal map. No decoder extension required.
Y-up. Units: meters. Origin: base center. Use the same scaling factor for the entire set.
Approximate dimensions: YINSH ring outer diameter 32 mm, opening 23.2 mm, height 3 mm; marker diameter 20.6 mm, height 2.5 mm. TZAAR diameter 28 mm, height 4.3 mm.
5,568–11,520 triangles per model. Actual counts and file sizes in validation.json.
All ten GLBs were checked for embedded textures and re-imported into Blender for preview.
Preview columns from left to right: YINSH ring, YINSH marker, Tzaar, Tzarra, Tott. Black row at back, ivory row at front.
