TZAAR piece GLBs (tott, tzarra, tzaar — black and white).

Same stone texture family as Tak/Yinsh. Committed files are meshopt-compressed with WebP textures. Before committing changes, run from web-3d:

  npm run compress-glb

Load at runtime via @abstract/three-engine (ensureMeshoptDecoderReady / loadGltfAsync).

Y-up, meters, base-centered origin. All three types share outer diameter and nominal thickness for stacking.

Piece names: publisher rulebook at https://www.spielezar.ch/modules/genzo_zar/views/pdf/spielregeln-tzaar.pdf (English, p. 7).
