# @abstract/pixi-shared

Shared Pixi v8 helpers for abstract-games web clients.

- **Stage / camera / hit** — ported from BimSavage `lib/pixi-stage` (`camera`, `hit`, `pointer-input`, `palette`, `destroy-application`, vanilla `createPixiStage`).
- **Yinsh visuals** — animated stage background, win-line glow/dust, selection/hover rings, AI strength HUD, worker AI bridge, Yinsh pan/zoom helper.

Games import `@abstract/pixi-shared` from the `web-pixi` npm workspace.
